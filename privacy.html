Privacy Policy

Last updated: 2026-11-07

What the app accesses

The app requests only the Google Drive scope drive.file. This lets it create files the user chooses to upload, and access only the files it created. It cannot see any other files in the user's Drive.

How data is used

Files the user selects are sent directly from the user's computer to the user's own Google Drive. The app does not send files or account data to any other server, does not store copies, and does not share or sell any data.

Where the sign-in is kept

The Google sign-in token is stored only in a local file on the user's own computer. Deleting that file, or removing the app at Google Account permissions, revokes access.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
